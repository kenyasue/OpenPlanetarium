# Requirements

## Overview

時間設定と観測地（現在地）設定の UI を刷新する。時間はコントロールバーの時刻表示クリックでカレンダー付きダイアログを開いて年月日・時刻を簡単に設定できるようにし、観測地はズーム可能な世界地図＋国/都市セレクトボックスで設定できるようにする。

## Background

現状の時間設定は `showDatePicker` / `showTimePicker` を個別に開く2ボタン方式で、時刻表示そのものはクリックできない。観測地設定は日本国内5都市のプリセットチップと緯度経度手入力のみで、海外都市や地図からの直感的な選択ができない。天文アプリとして世界中の任意地点・任意日時の空を素早く再現できることは基本価値（PRD の観測支援要件）であり、操作性の改善が必要。

## Features to Implement

### 1. 時間設定ダイアログ

- コントロールバーの時刻表示テキストをクリックすると時間設定ダイアログを表示する
- ダイアログにはカレンダー（`CalendarDatePicker` を埋め込み表示）を常時表示し、年月日をクリックで設定できる
- 時・分はドロップダウン等で簡単に設定でき、変更は即座に観測時刻へ反映される
- 「Now」リセットボタンを備える
- 既存の時計アイコン（edit_calendar）からも同じダイアログを開く（旧 `_TimeSettingsContent` は置き換え）
- **時間スライダーは現状維持**：現在設定されている日付の 0–24 時を表示する（既存挙動を壊さない）

### 2. 世界地図による観測地設定

- 世界地図（正距円筒図法）を表示し、陸地シルエットと主要都市を点で描画する
- 都市データは首都を含む世界の主要都市をできるだけ多く収録する（Natural Earth populated places 由来、1,000 都市以上を目標）。首都は色/形で区別する
- 地図は `InteractiveViewer` でパン・ピンチ/ホイールズームが簡単にできる
- 地図上をクリックすると、その地点の緯度経度が観測地として自動設定される
- 現在の観測地にマーカーを表示する

### 3. 国・都市セレクトボックス

- 国選択セレクトボックスと主要都市選択セレクトボックスを表示する
- 国を選択すると都市セレクトボックスの選択肢がその国の都市に自動でフィルタリングされる
- 都市を選択すると観測地がその都市に設定され、地図マーカーも移動する
- 地図クリック時はセレクトボックスも連動する（最寄り都市が一定距離内にあればその都市/国を選択状態にし、なければ未選択とする）
- 既存の緯度経度手入力・GPS 取得機能は維持する

## Acceptance Criteria

### 時間設定ダイアログ

- [ ] コントロールバーの時刻テキストをクリックするとダイアログが開く
- [ ] カレンダーが埋め込みで表示され、日付クリックで観測時刻の年月日が変わる（時刻は維持）
- [ ] 時・分を選択すると観測時刻に即反映される
- [ ] スライダーは従来どおり選択中日付の 24 時間を操作できる
- [ ] 日周運動再生中に日時を設定すると再生が停止する（既存挙動と一致）

### 世界地図による観測地設定

- [ ] 地図に陸地と都市の点が描画される
- [ ] ズーム・パンができる
- [ ] 地図クリックで緯度経度が観測地に設定され、ステータス表示に反映される
- [ ] 収録都市数が 1,000 以上である

### 国・都市セレクトボックス

- [ ] 国を選ぶと都市リストがその国のみになる
- [ ] 都市を選ぶと観測地が設定され、マーカーが移動する
- [ ] 地図クリックで近傍都市（150 km 以内）があればセレクトボックスに反映される

## Success Metrics

- flutter analyze / dart format / flutter test（既存 219 テスト＋新規テスト）がすべてパス
- オフラインで地図・都市データが動作する（アセット同梱、ネットワーク不要）

## Out of Scope

- タイムゾーン選択（表示はこれまでどおり端末ローカルタイム）
- 都市名の日本語ローカライズ（英語名のみ。既存 UI が英語のため）
- 国境線の描画（陸地シルエットのみ）
- 逆ジオコーディング API による地名解決（オフライン方針に反するため）
